Design System

The website’s visual language: palette, typography and components.

Warm ink and paper, the dartboard’s red as the one accent and its green for small signals, Insignia for headings, Inter for text and Cascadia Code for code. The landing page uses css/home.css, the documentation and release pages css/landing.css. Everything below is drawn with those two stylesheets, so this page shows the design as it is.
